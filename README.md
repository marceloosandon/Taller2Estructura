Instruccion para compilar en el codespace (entorno de linux):

Para Crear el ejecutable binario de linux (codespace), necesitas este comando en la terminal (se compila en linux, no correr ni descargar en windows, tira error de software)

g++ *.cpp -o (nombreProgramaQueQuierasPoner)

y luego de compilar ejecutar el comando para ejecutar el programa o archivo binario de linux

./nombreProgramaQueQuierasPoner

Después interactuar con el menú, tiene 4 opciones

 === HOSPITAL MARMAJA ===
1. Atender Pacientes // atiende pacientes 
2. Ver Departamento // ve por departamentos los pacientes guardados
3. Buscar Paciente // revisa por id o por nombre del usuario a buscar
4. Salir // sales del programa

Seleccionar opcion: 2

=== VER DEPARTAMENTOS ===
Seleccione la operacion:
1. Inorden //recorrido inorden
2. Preorden //recorrido Preorden
3. Postorden //recorrido postorden
4. Mostrar altura del arbol //muestra la altura del arbol
5. Mostrar factores de balance //muestra los factores de balance
6. Documentar estructura del arbol //resumen del arbol
Opcion:

Necesitas crear los archivos de los pacientes, en el repositorio están los archivos de cada paciente como ejemplo.
