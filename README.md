Instruccion para compilar en el codespace (entorno de linux):

Para Crear el ejecutable binario de linux (codespace), necesitas este comando en la terminal (se compila en linux, no correr ni descargar en windows)

g++ *.cpp -o (nombreProgramaQueQuierasPoner)

y luego de compilar ejecutar el comando para ejecutar el programa o archivo binario de linux

./nombreProgramaQueQuierasPoner

Después interactuar con el menú, tiene 4 opciones

 === HOSPITAL MARMAJA ===
1. Atender Pacientes // atiende pacientes 
2. Ver Departamento // ve por departamentos los pacientes guardados
3. Revisar Historial de Atencion // revisa por id o por nombre del usuario a buscar
4. Salir // sales del programa
